# Spring Boot Learning Journey 

This repository contains projects and notes from my Spring Boot learning journey.

## Phase 1 - Spring Core Fundamentals

### Concepts Covered
- Inversion of Control (IoC)
- Dependency Injection (DI)
- Spring Beans
- Bean Scopes
- Bean Lifecycle
- @Component
- @Autowired
- @PostConstruct
- @PreDestroy

## Projects

### 1. IoC Container
Understanding how Spring manages object creation and dependencies.

### 2. Laptop Dealer System
Practice project for Dependency Injection and Bean Management.

### 3. Voting Application
A console-based voting system built for learning Spring Core concepts.

#### Features
- User can vote for a political party.
- Admin can view all votes.
- Dependency Injection using @Autowired.
- Bean management using @Component.
- Bean Lifecycle using @PostConstruct and @PreDestroy.

## Tech Stack
- Java
- Spring Framework
- Maven

## Purpose

This repository is created purely for learning and practicing Spring Boot concepts before moving to REST APIs, Spring Data JPA, Security, and Microservices.

Learning one concept at a time and building projects along the way
