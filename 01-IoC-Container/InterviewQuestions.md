# IoC Container Interview Questions

## Q1. What is IoC?

Inversion of Control is a design principle where Spring manages object creation and dependencies.

## Q2. What is an IoC Container?

It is a container that creates, manages, configures, and injects Spring beans.

## Q3. Which IoC Containers are available in Spring?

1. BeanFactory
2. ApplicationContext

## Q4. Which one is preferred?

ApplicationContext because it provides additional enterprise features.

## Q5. Difference between IoC and Dependency Injection?

IoC is the principle.
Dependency Injection is one way to achieve IoC.
